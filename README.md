# idle-compact

Бот сжимает длинную переписку в краткую выжимку, чтобы не таскать
всю историю каждый раз. Сейчас он делает это в самый неудобный момент —
когда ты уже написал сообщение и ждёшь ответа: ты ждёшь минуту-полторы,
а платишь за перечитывание всего разговора по полному тарифу
(скидка за повторное чтение к тому моменту уже сгорела).

Плагин делает то же сжатие заранее: когда ты отошёл, а скидка ещё
действует. Возвращаешься — разговор уже короткий, ответ начинается
сразу, платишь за маленький объём вместо большого.

Замерено: ~10%+ экономии на активных днях + минуты несъеденного ожидания.

## Логика (простыми словами)

1. После каждого ответа ставится будильник: spark — 9 мин, deepseek — ~76 мин
   (скидка на повторное чтение живёт 10 и ~85 мин соответственно).
   Написал новое сообщение — будильник сброшен и поставлен заново.
2. Прозвенел, а ты всё ещё молчишь, разговор большой (больше ~150К токенов) —
   сжимаем прямо сейчас, пока перечитывание идёт со скидкой.
3. Жмёт само ядро Hermes тем же путём, что штатная чистка:
   с защитой от одновременного сжатия, от падения и от потери сообщений,
   если ты напишешь ровно в этот момент.
4. Короткие/свежие/служебные разговоры не трогаются.

## Поддерживаемые модели (провайдер opencode-go)

Замерено на живых сессиях, TTL вшит под них:

| Модель | TTL кеша | Таймер |
|---|---|---|
| `muse-spark-1.3-contributor` | 10 мин | 9 мин |
| `deepseek-v4.1-flash` | 85–90 мин | ~76 мин |

Другие модели: плагин работает (гейт и сжатие — от живого порога ядра),
но таймер берётся по умолчанию 10 мин — TTL под них не замерен.
Замер сделаем по логам и добавим строку в таблицу.

## Установка (одна команда)

Требуется установленный Hermes Agent.

```bash
hermes plugins install npetroff24/hermes-plugin-idle-compact --enable
```

Что произойдёт: плагин скачается с гитхаба, включится и подхватится
живым gateway без перезапуска. Ничего править руками не надо.

Проверка, что работает (в течение минуты появится строка):

```bash
grep -a "idle-compact" ~/.hermes/logs/gateway.log | tail -2
# idle-compact 0.2.0 loaded: DRY_RUN=False WRITE_ENABLED=True gate=150000
```

Дальше плагин сам ставит таймеры после каждого ответа и пишет
в тот же лог строки `timer ...`, `COMPRESS START/DONE`.

## Откат

```bash
hermes plugins disable idle-compact
```

Сжатие архивирует строки (`active=0`), не удаляет. Снапшоты активной
сессии перед первым боем — в `rollback_<session>.json` (не входят в репо).
