# idle-compact

Фоновое сжатие контекста Hermes-сессий **до** истечения prompt-cache модели.

## Зачем

Сжатие в критическом пути — это 70–100 сек ожидания + холодное чтение
большого контекста за полную цену (кеш уже протух). Плагин ставит таймер
`TTL × 0.9` после каждого ответа и сжимает, пока пользователя нет, а кеш
ещё жив: тёплое чтение стоит в ~50 раз дешевле холодного.

Замерено: ~10%+ экономии на активных днях + минуты несъеденного ожидания.

## Логика

1. После каждого хода — таймер (spark 9 мин, deepseek ~76 мин).
2. Сработал: сессия тиха, источник human, размер > гейта
   (гейт = цель × 1.5, цель = живой `threshold_tokens × target_ratio`).
3. Сжатие делает ядро (`resident._compress_context`, тот же путь что гигиена):
   локи, cooldown, anti-thrash, watermark против гонок.
4. Маленькие/молодые/cron-сессии не трогаются.

## Установка

```bash
hermes plugins install <git-url> --enable
```

## Откат

```bash
hermes plugins disable idle-compact
```

Сжатие архивирует строки (`active=0`), не удаляет. Снапшоты активной
сессии перед первым боем — в `rollback_<session>.json` (не входят в репо).
